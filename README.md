# Attendance Deploy Agent

This is my shell script for the ALU scripting summative lab.

## Features

Deploy the application

Run the app

Archive logs

## How to use
Run ./deploy_agent.sh and choose an option (1-4).

## Notes
I had trouble with the SIGTSTP signal, but I fixed it.
The script uses a trap to handle Ctrl+C and Ctrl+Z during deployment.
